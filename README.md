# redirector
A very basic program that redirects.

# Options
- `--port=PORT`
- `--host=HOST` (what to bind to, e.g. `0.0.0.0`)
- `--ssl=true|false`
- `--cert=CERT` (path to certificate file)
- `--key=KEY` (path to key file)
- `--db=SQLITE_DATABASE` (path to SQLite3 database)
- `--nfu=NF_URL` (where to redirect to for an unknown redirect id)
